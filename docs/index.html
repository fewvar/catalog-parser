результат работы парсера

Парсер каталога → Excel

Парсер обошёл каталог, зашёл в каждую карточку товара и собрал данные в таблицу. Ниже — то, что получилось: ищите, фильтруйте, выгружайте в Excel любой срез.

Данные собраны утилитой заранее и лежат рядом файлом — браузеру чужие сайты парсить не разрешают. Сам парсер работает из командной строки.

Товаров—
Категорий—
Средняя цена—
Диапазон—

Загружаю данные каталога…

Как это собрано

  • Парсер идёт по пагинации до конца каталога и заходит в каждую карточку товара.
  • Из карточки берётся то, чего нет в списке: артикул, категория, остаток на складе, отзывы, описание.
  • Цена разбирается в число с отделением валюты, рейтинг из CSS-класса превращается в цифру.
  • Между запросами выдерживается пауза, при временной ошибке запрос повторяется с нарастающей задержкой.
  • На выходе — Excel с листом товаров и листом сводки по категориям.

Разбор разметки вынесен в отдельный модуль: под другой сайт-каталог меняются только CSS-селекторы, остальное работает как есть. Исходный код на GitHub.
