# Парсер каталога → Excel

Собирает карточки товаров с сайта-каталога в аккуратную Excel-таблицу:
название, цена, наличие, рейтинг, характеристики, описание.

**[Посмотреть результат →](https://fewvar.github.io/catalog-parser/)** — 1000 собранных
товаров с поиском и фильтрами, выгрузка в Excel прямо со страницы.

## Задача

Каталог на тысячу позиций, данные нужны в таблице: сравнить цены, посчитать
средние по категориям, загрузить в свою систему. Руками — несколько дней
копирования. Парсером — пара минут.

## Решение

```bash
python3 parse.py --all -o каталог.xlsx
```

Утилита обходит пагинацию, заходит в каждую карточку товара за характеристиками,
чистит данные и складывает всё в Excel с двумя листами.

## Что внутри

- **Обход пагинации** — идёт по ссылке «next», пока страницы не кончатся.
- **Заход в карточку товара** за тем, чего нет в списке: артикул, категория,
  остаток на складе, количество отзывов, описание.
- **Чистка данных** — цена разбирается в число с отделением валюты, рейтинг из
  CSS-класса превращается в цифру, переносы строк схлопываются.
- **Вежливость к сайту**: пауза между запросами, честный User-Agent, повтор при
  временных ошибках с нарастающей задержкой. Парсер не создаёт нагрузку и не
  выглядит как атака.
- **Устойчивость** — недоступная карточка пропускается, сбор продолжается;
  сеть отвалилась — понятное сообщение вместо стектрейса.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Использование

```bash
python3 parse.py                      # 3 страницы, с характеристиками
python3 parse.py --all                # весь каталог
python3 parse.py --pages 10 --no-details   # быстро, только из списка
python3 parse.py --all --json данные.json  # ещё и JSON
```

Параметры:

```
-p, --pages N      сколько страниц обойти (по умолчанию 3)
-a, --all          весь каталог целиком
-o, --out ФАЙЛ     куда сохранить Excel (по умолчанию каталог.xlsx)
    --json ФАЙЛ    дополнительно выгрузить в JSON
    --no-details   не заходить в карточки — быстрее, но без характеристик
-d, --delay СЕК    пауза между запросами (по умолчанию 0.5)
    --url АДРЕС    стартовая страница каталога
-q, --quiet        меньше вывода
```

## Про адаптацию под другой сайт

Разбор разметки вынесен в `catalog/scraper.py` — две функции: `parse_listing`
для страницы списка и `parse_product_page` для карточки товара. Под новый сайт
меняются только CSS-селекторы в них; загрузка, паузы, повторы, выгрузка в Excel
и сводка остаются как есть.

В качестве цели взят [books.toscrape.com](https://books.toscrape.com) — сайт,
специально созданный для обучения парсингу.

## Тесты

```bash
python3 tests/test_parsing.py
```

28 проверок разбора: цены в разных форматах, рейтинги, остатки, страница списка,
карточка товара, поведение на битой разметке. Работают на сохранённых страницах —
сеть не нужна, сайт не дёргается.

## Структура

```
parse.py               командный интерфейс
catalog/fetcher.py     загрузка страниц: паузы, повторы, таймауты
catalog/scraper.py     разбор разметки — список и карточка товара
catalog/exporter.py    выгрузка в Excel и JSON
tests/                 проверки разбора на сохранённых страницах
docs/                  веб-версия результата
```
